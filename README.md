# Figure Store Management System

An E-commerce and Management System for an Anime Figure Store, built with ASP.NET MVC and Entity Framework. 

## Team Project Overview
This project was developed by a team of **3 members** as part of a university assignment. 

### My Role & Contributions
As a core developer in this project, I was responsible for building essential user-facing features and authentication modules, including:
- **Authentication System:** Developed the Registration and Login functionality, ensuring secure user access.
- **Product Detail Page:** Designed and implemented the UI and data binding for viewing detailed figure information.
- **Shopping Cart Module:** Collaborated on building the shopping cart logic, allowing users to add, update, and remove items.
- **UI/UX Layout:** Contributed to the overall responsive layout and design of the customer-facing website.

### Other Team Members' Contributions
To ensure a complete application, I collaborated with two other talented team members:
- **Member 1:** Developed the Products page, Sidebar navigation, Checkout/Payment processing, and co-developed the Layout and Shopping Cart.
- **Member 2:** Exclusively developed the Admin Dashboard and all related administrative CRUD functionalities (Products, Users, Orders management).

## Technology Stack
- **Framework:** ASP.NET MVC 5
- **Language:** C#
- **ORM:** Entity Framework
- **Database:** Microsoft SQL Server
- **Frontend:** HTML, CSS, Bootstrap, jQuery
