# Figure Store Management System

An E-commerce and Management System for an Anime Figure Store, built with ASP.NET MVC and Entity Framework. 

## Project Description
This web application provides a complete solution for managing an online figure store. It includes a user-friendly storefront for customers to browse, manage their cart, and purchase products, alongside a comprehensive administrative dashboard for managing inventory, orders, and users.

## Key Features

### Customer Side
- **User Authentication:** Secure registration, login, and profile management.
- **Product Catalog:** Browse figures by categories, brands, or search by keywords.
- **Product Details:** View comprehensive information, specifications, and images for each figure.
- **Shopping Cart:** Add items, update quantities, and remove products dynamically.
- **Checkout Process:** Secure order placement and billing information handling.

### Admin Dashboard
- **Product Management:** Full CRUD (Create, Read, Update, Delete) operations for inventory.
- **Order Management:** Track customer orders, update order status, and view invoices.
- **User & Staff Management:** Manage customer accounts and administrative privileges.
- **Revenue Statistics:** Track sales and view revenue reports over time.
